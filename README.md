# 🔤 Palavra Secreta

> Jogo de adivinhação de palavras para dois jogadores, rodando direto no terminal!

---

## 📖 Sobre o Projeto

**Palavra Secreta** é um jogo em Python para dois jogadores:

- O **Jogador 1** escolhe uma palavra secreta
- O **Jogador 2** tenta adivinhar a palavra, letra por letra
- Cada letra correta é revelada na posição certa — as demais ficam como `*`

O jogo continua até o Jogador 2 descobrir todas as letras da palavra!

---

## 🎮 Como Funciona (Exemplo)

```
Palavra secreta: * * * * * *   → (6 letras)

Chute uma letra: p
Palavra secreta: p * * * * *

Chute uma letra: t
Palavra secreta: p * * * * *   (letra não encontrada)

Chute uma letra: y
Palavra secreta: p y * * * *

... e assim até completar: p y t h o n  🎉
```

## 🚀 Como Rodar o Jogo

### Pré-requisitos

Você precisa ter o **Python** instalado na sua máquina.

> Não tem Python? Baixe em: https://www.python.org/downloads/

Para verificar se já está instalado, abra o terminal e digite:

```bash
python --version
```

Se aparecer algo como `Python 3.x.x`, está tudo certo!

---

### Passo a Passo

**1. Clone o repositório** (baixe o projeto para o seu computador):

```bash
git clone https://github.com/mdudagualberto/jogo-palavra-secreta.git
```

**2. Entre na pasta do projeto:**

```bash
cd jogo-palavra-secreta
```

**3. Execute o jogo:**

```bash
python jogo_palavra_secreta.py
```
